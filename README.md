# MyTasks

HTMLファイル1枚で動く、自分専用のタスク管理アプリ。

- **依存ゼロ** — ビルド不要、npm 不要、外部CDN・ライブラリなし
- **オフライン動作** — 外部への通信は一切なし
- **ログイン不要** — データはブラウザの localStorage にだけ保存される

**▶ すぐ試す: https://tsubasagit.github.io/mytasks/**

## 使い方

上記URLをブラウザで開くか、リポジトリを clone して `index.html` を開くだけ。

ただし `file://` で開くとブラウザによっては localStorage が使えず保存されないため、
常用する場合はローカルサーバー経由で開くことを推奨します。

```bash
python -m http.server 8945 --directory .
```

→ http://localhost:8945

初回は空の状態です。「サンプルを入れて試す」ボタンからひと通りの動きを確認できます。

## クイック追加の記法

入力欄に1行書くだけで、プロジェクト・期限・優先度・繰り返しをまとめて設定できます。

```
請求書を送る #経理 @明日 !
```

| 記法 | 意味 | 例 |
|---|---|---|
| `#名前` | プロジェクト | `#経理` `#開発` |
| `@日付` | 期限 | `@今日` `@明日` `@明後日` `@金` `@8/31` `@2026-09-01` `@+3`（3日後） `@来週` `@週末` |
| `!` | 優先度：高 | |
| `!!` | 優先度：最優先 | |
| `*毎日` `*毎週` `*毎月` | 繰り返し | 完了すると次回分が自動生成される |

## 機能

- **4つのビュー** — 今日 / 今週 / すべて / 完了
- **自動グルーピング** — 期限切れ・今日・明日・今週・これから・期限なし
- **繰り返しタスク** — 完了した瞬間に次回分を自動生成
- **インライン編集** — 行をクリックしてタイトル・プロジェクト・期限・優先度・繰り返し・メモを編集
- **期限クイック操作** — 今日 / 明日 / +1週 / 期限なし
- **プロジェクト絞り込み・全文検索**
- **削除の取り消し** — トーストから7秒以内に復元
- **JSON 書き出し / 読み込み** — バックアップ・端末間の移行に
- **Markdown コピー** — `- [ ] タスク` 形式で日報・議事録にそのまま貼れる
- **ダーク / ライトテーマ** — OS設定に追従、手動切替も可能
- **レスポンシブ** — スマホでは1カラム

### キーボードショートカット

| キー | 動作 |
|---|---|
| `n` | 追加欄にフォーカス |
| `/` | 検索欄にフォーカス |
| `Esc` | 編集を閉じる |

## データについて

- 保存先はブラウザの localStorage（キー `mytasks.v1`）のみです。サーバーには何も送信されません。
- **保存先はURL（オリジン）ごとに分かれます。** GitHub Pages 版とローカルで開いた版、PCとスマホは、それぞれ別のリストになります。移行したい場合は「JSON書き出し」→「JSON読み込み」を使ってください。
- そのため **ブラウザのデータを削除すると消えます**。また端末やブラウザをまたいだ共有もされません。
- 定期的に「JSON書き出し」でバックアップを取ってください。別端末へは「JSON読み込み」で移せます（既存IDは上書きせずスキップ）。
